# 국제교류 실무 영상 강의실

「국제교류수업 운영 매뉴얼」(2026. 11. 10. 최종수정본)을 챕터별 내레이션 영상 9편으로 따라 배우는 정적 웹사이트입니다.

- `index.html`: 시작 페이지(실제 대륙을 그린 3D 지구본, 다크 모드 지원)
- `lecture.html`: 강의실(왼쪽 목차, 영상·자막, 장면 목차, 업무 체크리스트, 근거자료, 검색)
- `data.js`: 챕터·장면·자막 데이터
- `videos/*.mp4`, `posters/*.jpg`: 영상과 표지
- `assets/`: 대륙 지도 데이터(world-atlas 110m), 소개 일러스트

영상 내레이션은 AI 음성(Supertone Supertonic 3, M2)입니다.
영상을 만드는 빌드 스크립트는 원본 저장소 `lipower14-coder/intl-exchange-lecture-2026`의 `build/` 폴더에 있습니다.
